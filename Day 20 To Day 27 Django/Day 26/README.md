# Day 26 – Django REST Framework Fundamentals

## Objective
Understand Django REST Framework fundamentals and learn how to develop RESTful APIs for managing employees, projects, and tasks.

## Topics Covered
- REST Architecture and API Principles
- HTTP Methods and Status Codes
- JSON Request and Response
- Serializers and Validation
- APIView and Generic Views
- ViewSets and Routers
- CRUD Endpoints
- Error Responses and API Conventions

## Practical Tasks
- Install and configure Django REST Framework.
- Build Employee REST APIs.
- Build Project REST APIs.
- Build Task REST APIs.
- Implement API input validation.
- Handle JSON requests and responses.
- Test API endpoints using Postman.
- Verify CRUD operations and HTTP status codes.

## Project Work
Expose the core functionality of the Employee and Task Management System through REST APIs using Django REST Framework.

Implement API endpoints for employee, project, and task management with proper serializers, validation, and error handling.

## Project Development Structure

This folder is maintained for day-wise internship tasks, learning progress, practical exercises, and documentation.

The actual Django project source code is maintained separately in the **Main Django Project** folder. All Django development and code updates are managed there.

## Technologies Used
Python, Django, Django REST Framework, REST APIs, JSON, Postman, SQLite/MySQL, VS Code.
