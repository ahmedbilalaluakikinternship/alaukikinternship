# Day 23 – Forms, ModelForms and CRUD

## Objective
Understand Django Forms and ModelForms and implement CRUD operations for employees, projects, and tasks with proper server-side validation.

## Topics Covered
- HTML Forms and Django Forms
- ModelForms
- GET and POST Requests
- Server-Side Validation
- CSRF Protection
- Success and Error Messages
- Create, Read, Update and Delete (CRUD) Operations
- Introduction to Class-Based Views

## Practical Tasks
- Implement Employee CRUD operations.
- Implement Project CRUD operations.
- Add Task Creation and Editing functionality.
- Validate user inputs on the server side.
- Display useful success and error messages.
- Implement CSRF protection for form submissions.

## Project Work
Complete the primary application workflows by integrating Django Forms, ModelForms, validation, and CRUD functionality into the application.

## Project Development Structure

This folder is maintained for day-wise internship tasks, learning progress, practical exercises, and documentation.

The actual Django project source code is maintained separately in the **Main Django Project** folder. All Django development and code updates are managed there.

## Technologies Used
Python, Django, Django Forms, ModelForms, HTML5, CSS3, Bootstrap, SQLite/MySQL, VS Code.
