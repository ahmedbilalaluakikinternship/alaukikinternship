# Day 24 – Authentication and Authorization

## Objective
Understand Django Authentication and Authorization and implement secure user access with role-based permissions.

## Topics Covered
- Django User Model
- Password Hashing
- User Registration, Login and Logout
- Sessions and Cookies
- Password Reset Workflow
- Groups and Permissions
- Role-Based Access Control (RBAC)
- Admin, Manager and Employee Roles
- Authentication vs Authorization

## Practical Tasks
- Implement User Login and Logout functionality.
- Restrict application pages based on user roles.
- Prevent unauthorized access to tasks and projects.
- Configure user groups and permissions.
- Test permission boundaries for different user roles.

## Project Work
Implement secure user access and role management by integrating Django Authentication, Authorization, Groups, and Permissions into the application.

## Project Development Structure

This folder is maintained for day-wise internship tasks, learning progress, practical exercises, and documentation.

The actual Django project source code is maintained separately in the **Main Django Project** folder. All Django development and code updates are managed there.

## Technologies Used
Python, Django, Django Authentication, Django Sessions, Django Permissions, HTML5, CSS3, Bootstrap, SQLite/MySQL, VS Code.
