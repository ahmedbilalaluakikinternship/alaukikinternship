# Day 25 – Advanced Django Features

## Objective
Understand advanced Django features and improve the application's functionality, maintainability, and overall development workflow.

## Topics Covered
- Function-Based Views and Class-Based Views
- Generic Views
- Custom Middleware
- Django Signals and Their Trade-offs
- Pagination and Filtering
- File Uploads and Storage
- Email Configuration
- Custom Management Commands
- Error Handling and Request Lifecycle

## Practical Tasks
- Implement task filters based on status, priority, and other relevant fields.
- Add pagination to the task listing page.
- Create a custom management command to generate sample data.
- Implement file upload functionality.
- Configure Django development email output.
- Test filtering, pagination, file uploads, and email functionality.

## Project Work
Improve the maintainability of the Employee and Task Management System by adding supporting features such as task filtering, pagination, file uploads, email configuration, and custom management commands.

## Project Development Structure

This folder is maintained for day-wise internship tasks, learning progress, practical exercises, and documentation.

The actual Django project source code is maintained separately in the **Main Django Project** folder. All Django development and code updates are managed there.

## Technologies Used
Python, Django, Django ORM, Django Generic Views, HTML5, CSS3, Bootstrap, SQLite/MySQL, VS Code.
