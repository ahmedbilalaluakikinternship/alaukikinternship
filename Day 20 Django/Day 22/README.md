# Day 22 – Django Models and ORM

## Objective
Understand Django Models and ORM and implement the main database structure for the project.

## Topics Covered
- Django Models and Fields
- Model Relationships
- ForeignKey, OneToOneField and ManyToManyField
- Migrations and Schema Changes
- Django ORM Queries
- Model Validation and Constraints
- Model Methods and Meta Options
- Django Admin Configuration

## Practical Tasks
- Create User Profile models.
- Create Employee, Project, Membership and Task models.
- Apply database migrations.
- Register models in Django Admin.
- Test model relationships and validations.
